“会议通知”App 隐私政策

生效日期：2026 年 7 月 11 日

“会议通知”App（以下简称“本 App”）用于将用户提供的会议通知文字整理为日历事件。我们重视您的隐私，本政策说明本 App 如何处理信息。

1. 我们处理的信息

  • 会议通知内容：用于识别会议名称、时间、地点、参会人员和会议内容，并生成待确认的日历事件。
  • 语音内容：仅在您主动使用语音输入时，调用 iOS 提供的麦克风和语音识别能力将语音转换为文字。
  • 日历信息：仅在获得您的授权后，将您确认的会议信息写入系统日历。
  • API 密钥：您可自愿填写第三方 AI 服务的 API 密钥。密钥仅保存在本机系统钥匙串中。

2. 信息的使用方式

本 App 的主要内容是会议通知整理与日历导入。相关信息仅用于提供这些功能、完成您主动发起的操作，不用于广告投放、广告追踪、用户画像或跨 App/网站追踪。

3. AI 分析和第三方服务

当您主动选择“智能导出”时，本 App 会使用您配置的 API 密钥，将待处理的会议通知文字发送给您选择的智谱 AI 或阿里云通义千问服务，以返回结构化会议信息。该处理受相应服务商的隐私政策与服务条款约束。如果您不希望将通知文字发送给 AI 服务，请使用“立即导出”的本地处理方式。

4. 信息共享

我们不出售您的个人信息，不将您的信息共享给与本 App 功能无关的第三方。仅当您主动使用系统语音识别、日历写入或上述 AI 分析功能时，才会向完成该功能所必需的系统或服务提供商传递相关信息。

5. 信息存储与保护

本 App 不运营用于收集会议通知内容的自有服务器。API 密钥保存在本机系统钥匙串中；日历事件由 iOS 系统日历管理。您可在 App 设置中删除已保存的 API 密钥，并可在 iOS 设置中撤回麦克风、语音识别或日历权限。

6. 儿童隐私

本 App 不专门面向儿童，也不会故意收集儿童个人信息。

7. 政策更新

如果本政策发生重要变更，我们会在本页面发布更新内容并修改生效日期。

8. 联系我们

如对本隐私政策有疑问，请发送邮件至 xwbj@hotmail.com。
