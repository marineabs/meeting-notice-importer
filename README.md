# 会议通知导入

一个把微信、短信、邮件中的会议文字通知整理为 iPhone 日历事件的原生 iOS App。

## 当前 MVP

- 手动粘贴会议通知
- 本地提取主题、日期、起止时间、地点、线上链接和参会人员
- 对相对日期、缺失日期/时间和默认结束时间给出提示
- 写入前编辑确认
- 将会议通知原文写入日历备注
- 设置日历提醒
- 通过 EventKit 写入系统默认日历
- 优先使用智谱 GLM-4.7-Flash，失败时自动调用千问 qwen-flash，两者均失败时回退本地规则
- API Key 仅保存在系统钥匙串

## 运行

使用 Xcode 打开 `MeetingImporter.xcodeproj`，选择 iOS 17 或更高版本的模拟器/真机运行。

日历写入需要用户在首次操作时授权。真机最适合验证系统日历结果。
